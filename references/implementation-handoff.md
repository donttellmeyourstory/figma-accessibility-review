# Передача в разработку и QA

Макет позволяет сформулировать ожидания, но следующие проверки требуют работающего интерфейса. Запускай их только при наличии запроса на проверку реализации и соответствующих инструментов. Записывай платформу, браузер, вспомогательную технологию, версии, шаги и наблюдения.

| Область | Проверка на реализации |
|---|---|
| Клавиатура | Все существенные действия достижимы; порядок разумен; фокус виден и не скрыт полностью; отсутствуют ловушки |
| Скринридер | Имена, роли, значения, состояния и связи объясняют сценарий; отдельные действия карточек сохраняются |
| Ошибки и обновления | Ошибка связана с вводом; существенные сообщения доступны без неоправданного нарушения текущей работы |
| Диалог | Проверены начальный фокус, ограничение взаимодействия с фоном для модального окна, закрытие и разумный возврат |
| Увеличение | Веб-текст увеличивается до 200% без потери содержимого и функций, с применимыми исключениями |
| Reflow | Проверена ширина 320 CSS px для вертикального содержимого; например, при 400% zoom исходного viewport шириной 1280 CSS px; учтены исключения |
| Текстовые интервалы | Пользовательские значения по 1.4.12 не приводят к потере информации или управления |
| Сенсорные требования | Обязательные шаги имеют необходимые альтернативы визуальным, звуковым или речевым действиям |
| Медиа | Проверены применимые субтитры, текстовые альтернативы и аудиоописания |

Для модальных окон используй соответствующий платформе паттерн. Не назначай универсально фокус заголовку или кнопке закрытия. Не предписывай aria-owns, aria-hidden или конкретную ARIA-разметку по расположению слоёв Figma.

Скрытая визуальная подпись может оставаться доступной скринридеру. Содержимое ниже viewport не равнозначно закрытой панели. Фактическое исключение из дерева доступности проверяют в реализации.

Автоматические проверки дают только часть покрытия. Отдельно проведи ручной основной сценарий клавиатурой и скринридером; отсутствие автоматически найденных ошибок не означает доступность продукта.

Источники: [ARIA APG: modal dialog](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/), [Resize text](https://www.w3.org/WAI/WCAG22/Understanding/resize-text.html), [Reflow](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html), [Text spacing](https://www.w3.org/WAI/WCAG22/Understanding/text-spacing.html).
